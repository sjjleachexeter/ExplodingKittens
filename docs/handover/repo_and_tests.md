# Repository Layout
1. `docs/`  - contains project documentation
2. `DjangoFramework/` - contains main django project 
   1. `DjangoFramework/DjangoFramework` - overall settings for django
   2. `DjangoFramework/gamification` - missions and quiz app
   3. `DjangoFramework/Leaderboard` - leaderboard app
   4. `DjangoFramework/nginx` - NGIX config for docker deployment
   5. `DjangoFramework/passport` - passport editing and creation 
   6. `DjangoFramework/Scanner` - barcode scan page
   7. `DjangoFramework/UI` - overall UI, navigation and project theme
   8. `DjangoFramework/Users` - uses management


# Tests
1. setup development environment
2. from `DjangoFramework` run `python manage.py test`
